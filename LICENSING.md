# Licensing and third-party terms

**No repository-wide software or data licence has been applied.** A paper's licence does not establish ownership of every supplied script, annotation or dataset. Until copyright ownership and a software licence are confirmed, public availability of this repository should not be read as a new permission grant. This intentionally replaces an unsupported blanket LICENSE file.

| --- | --- |
| Published paper and reference table | Tavakoli and Sanderson (2026), DOI 10.1145/3805712.3808545. Uploaded paper carries CC BY 4.0; the result CSV is an attributed transcription. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). |
| Supplied original retrieval script | Preserved byte-for-byte. Its source carried no licence notice; original ownership/reuse authority needs confirmation. |
| Newly prepared release tools/docs | Added during release preparation and explicitly distinguished from original experimental code. Choose a software licence after confirming rights and incorporated material. |

The official FEVER notice refers to Wikipedia article terms, with CC BY-SA 3.0 where article terms are unavailable. This repository does not relabel those materials as MIT or assert a broader new data licence. [Upstream FEVER notice](https://fever.ai/download/fever/license.html). |
| Candidate harm/forget annotations | Hypothetical benchmark-policy metadata. Creators, source relationship and redistribution terms need author review. They are not legal findings or verified personal facts. |
| Llama / verifier / search dependencies | Acquire separately under their own terms. No weights, Java binaries or dependency code are bundled. Llama 3 has a separate community licence. |

For author-owned original software, **MIT is the recommended simple option**, subject to ownership/coauthor and incorporated-code checks. See the [official MIT text](https://opensource.org/license/mit). Add a root LICENSE only after filling its correct copyright holder/year and confirming that scope. Keep data and third-party notices separate. Do not apply MIT to the entire data/model collection.

The initial upload folder omits claim text, answer strings and raw ranked-list exports. Its identifier/annotation manifests still need their own provenance review; omission of text is not a declaration that all remaining rights questions disappear. Full source-text redistribution requires the corresponding attribution/notice review before files are added.
