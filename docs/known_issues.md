# Known artefact and reporting questions

These are findings about candidate supplied files, not corrections to the published paper. [The additional-artefact review](additional_artifacts.md) records the later 200-case traces, separate 20-case diagnostic and unequal Keep coverage. The printed report card is preserved unchanged.

1. **Target/scope versions.** The 3,690-query/630-target pool and 3,542-query/605-target resolved view differ on 41 shared target assignments; ten changes occur in the 1,000-query sample. The masks share 591 IDs. No resolver/alias/selection implementation or final run manifest determines which policy boundary was used in publication.
2. **Stored PRE flags.** The supplied PRE TSV records zero exposure everywhere. Existing served lists yield 973/1,000 events under pool630 or 974/1,000 under resolved605. The original script writes zero if no mask is supplied; this is a possible cause, not proven historical execution evidence.
3. **FILT scope sensitivity.** Supplied FILT raw lists equal PRE on all 1,000 queries. Filtering by pool630 reproduces every served list and gives zero exact-ID exposure. Under resolved605, 53/1,000 served lists have an event. Both are labelled scope-dependent file analyses, not answer leakage or replacement published values.
4. **Scoring denominators.** A supplied summary declares N_total=200 for each Forget/Keep state. If N_score is non-abstention, Forget abstention percentages match Table 5. N_cite/N_total gives 64.0/8.0/9.5, while the paper defines CiteCov over non-abstentions. The later raw generation trace has strict flags 34/200, 1/200 and 2/200, matching the printed leakage percentages. Its 1,000-labelled companion is empty; the original detector and final table run remain unverified. Raw Forget citation-list counts are 128/16/20, while the count summary reports 128/16/19; abstention/eligibility rules are not supplied. Do not multiply counts by five or silently change its denominator.
5. **Intervals.** Numerator/denominator/procedure recovery is necessary. Conditional Wilson checks do not match some printed intervals, e.g. 5/1,000 gives approximately [0.214,1.165]%, rather than printed [0.2,1.4]%. This is arithmetic under a specified count, not a demonstrated paper correction.
6. **Keep populations.** Candidate 723-page, 6,942-query and 9,855-query views are distinct. The larger view's 10,140 rows are unique query-target pairs, not duplicate queries to discard. New PRE/POST rank exports cover 11,090 versus 106,120 queries, with PRE's pair sequence a prefix of POST. A separate 65,000-query PRE diagnostic has case/duplicate issues. No matched FILT ranks or identified 8,268-control manifest is supplied.
7. **HWE and swaps.** All candidate weights are 1.0. New multi-target ranks exactly reproduce the category means as any-gold-target hit@10, resolving the mismatch with selected-single-target rates. This event is not global forbidden-record exposure, and the original producing code/run remains unverified. All 150 swap baseline answers/top-k lists now link exactly to the larger generation trace, but it still has only a three-variant request label; no actual swap results are established. The paper's instantiated AR-ES is neutral-only.
8. **Incomplete execution assets.** The supplied 197 MiB ZIP omits two declared stored-field files. No complete index pair, corpus recipe or original environment exists in this package. Generation/scoring code is absent; malformed/debug/TODO inputs are excluded.

Author review should resolve original run identity, policy scope, denominator definitions, utility population and third-party rights before expanding the release or describing it as fully reproducible.
